hi this is my python assignment for hostel student record system. i made this using plain python code with no modules imported.

## why i made this
in hostel we need to keep track of students room numbers and state and registration number. so i created this project so we can save student data in txt file easily.

## features in this project
* add student record (asks name room no reg no email password state)
* display student list in table
* search student by reg number
* delete record
* edit or update student data
* filter student by hostel block like 7B or by home state

## how to run code
1. install python on pc
2. open terminal in project folder
3. run command: python student_record_system.py

## file structure
student_record_system.py - main code file
students.txt - file where data saved automatically

## issues i faced
sometimes if students.txt format is wrong program might skip line. also if room number format is typed wrong it will still save.
